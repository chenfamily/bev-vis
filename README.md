# BEV Trajectory Visualization — step12 (Standalone)

A standalone Python script that renders, per driving scene, a synchronized
**6-camera view + Bird's-Eye-View (BEV)** video from the [nuScenes](https://www.nuscenes.org)
dataset. A single vehicle is tracked across the scene and highlighted
consistently in both the camera images and the BEV panel, alongside
multi-modal future trajectories and an attention heatmap.

> **Honesty notice**
> Point clouds, camera images, and ground-truth boxes/trajectories are **real nuScenes data**.
> The **multi-modal trajectory branches** and the **attention heatmap** are
> **synthetic illustrations**, generated by simple heuristics (future path, nearby
> agents) — **not** the output of a trained model. No detection/prediction model
> is included in this repository. Output is labeled "* illustrative" accordingly.

> **Note on language:** All plot text (titles, axis labels, legends) is in
> English by design, regardless of the environment's installed fonts. This
> avoids CJK glyph-rendering issues (missing-font `findfont` warnings, "tofu"
> boxes, or garbled characters) that can occur inconsistently across
> different operating systems and containers — including inside this
> project's own Docker image, which does not bundle CJK fonts.

---

## What it does

- Loads a driving scene from nuScenes and steps through all its frames.
- For each frame, renders the 6 surround camera views with 3D box overlays.
- Builds a BEV panel from the real LiDAR point cloud, with:
  - vehicle boxes and pedestrian markers,
  - multi-modal future trajectories (time-gradient colored, illustrative),
  - a synthetic attention heatmap around one tracked vehicle,
  - the same tracked vehicle highlighted (yellow box + fill) in whichever
    camera view currently sees it.
- Selects the tracked vehicle automatically (present across many frames,
  moves noticeably, tends to be forward of the ego vehicle).
- Exports the result as an MP4 (`sceneN_highlight.mp4`).

## Coordinate convention

nuScenes LiDAR frame: `index0 = lateral (left/right)`, `index1 = longitudinal
(forward/back)`. BEV plotting: x-axis = lateral, y-axis = longitudinal,
ego heading points up.

## Requirements

Either:

- **Docker** (recommended — guarantees identical results on any machine), or
- **Local Python 3.10** with the packages in `requirements.txt`, plus `ffmpeg`
  for video export.

## Get the nuScenes dataset

This repository does **not** include the dataset (its license prohibits
redistribution). To obtain it:

1. Register at <https://www.nuscenes.org/nuscenes>.
2. Download the **Mini** split (`v1.0-mini`, ~4 GB) or a full split.
3. Extract so that `v1.0-mini/`, `samples/`, `sweeps/`, and `maps/` sit
   alongside each other under one directory.

## Run with Docker (recommended)

### 1. Build the image

```bash
docker build -t bev-vis .
```

### 2. Run

Run this from the project folder that contains `Dockerfile`, your `v1.0-mini/`
dataset folder, and an `output/` folder (create it first if it doesn't exist:
`mkdir -p output`):

```bash
cd ~/bev-vis   # the folder containing Dockerfile, v1.0-mini/, and output/

docker run --rm \
  -v "$(pwd)/v1.0-mini:/data:ro" \
  -v "$(pwd)/output:/app/output" \
  -e NUSC_ROOT=/data \
  -e OUT_DIR=/app/output \
  bev-vis \
  python step12_video_highlight.py --scene 0
```

If your dataset lives elsewhere, replace `"$(pwd)/v1.0-mini"` with the
absolute path to your `v1.0-mini` folder (the one containing `maps/`,
`samples/`, `sweeps/`, and an inner `v1.0-mini/` metadata folder).

The output video appears in your mounted `output` folder.

**Windows PowerShell:**

```powershell
docker run --rm `
  -v D:\path\to\nuscenes:/data:ro `
  -v D:\path\to\output:/app/output `
  -e NUSC_ROOT=/data `
  -e OUT_DIR=/app/output `
  bev-vis `
  python step12_video_highlight.py --scene 0
```

## Run locally (conda)

```bash
conda create -n bev_vis python=3.10 -y
conda activate bev_vis
pip install -r requirements.txt
conda install -c conda-forge ffmpeg -y

# edit NUSC_ROOT inside the script, or set it as an environment variable
python step12_video_highlight.py --scene 0
```

## Usage

```bash
python step12_video_highlight.py             # scene 0
python step12_video_highlight.py --scene 3   # a specific scene
```

`NUSC_ROOT` and `OUT_DIR` environment variables override the dataset path
and output directory; both default to sensible local paths if unset.
