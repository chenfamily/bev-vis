# BEV Trajectory Visualization (Standalone Scripts)

Two standalone Python scripts that visualize multi-camera + Bird's-Eye-View
(BEV) driving scenes from the [nuScenes](https://www.nuscenes.org) dataset:

- **`step10_final.py`** — interactive scene/frame explorer. Lets a user pick
  any scene and frame from the dataset and renders a single image (6 camera
  views + BEV panel with detections, multi-modal trajectories, and an
  attention heatmap).
- **`step12_video_highlight.py`** — renders a full scene as an MP4 video, with
  one vehicle tracked and highlighted consistently across all camera views
  and the BEV panel throughout.

> **notice**
> Point clouds, camera images, and ground-truth boxes/trajectories are **real nuScenes data**.
> The **multi-modal trajectory branches** and the **attention heatmap** are
> **synthetic illustrations**, generated by simple heuristics (future path, nearby
> agents) 

> **Note on language:** All plot text (titles, axis labels, legends) is in
> English by design, regardless of the environment's installed fonts. This
> avoids CJK glyph-rendering issues (missing-font `findfont` warnings, "tofu"
> boxes, or garbled characters) that can occur inconsistently across
> different operating systems and containers — including inside this
> project's own Docker image, which does not bundle CJK fonts.

## What each script does

### `step10_final.py` — interactive scene explorer

- Lists all scenes in the loaded nuScenes split, with frame counts and
  descriptions.
- Prompts the user to pick a scene index, then a frame index within it
  (or auto-picks the frame with the most obvious vehicle motion via `--auto`).
- Renders that single frame: 6 camera views with 3D box overlays, plus a BEV
  panel with vehicle boxes, pedestrian markers, multi-modal future
  trajectories, and a synthetic attention heatmap around the most-active
  vehicle.
- Saves the result as a PNG.

### `step12_video_highlight.py` — tracked-vehicle video

- Steps through every frame of a chosen scene.
- Automatically selects one vehicle to track (present in many frames, moves
  noticeably, tends to be ahead of the ego vehicle) and highlights it
  consistently — yellow box + fill in whichever camera currently sees it, and
  a yellow box + attention heatmap in the BEV panel.
- Exports the result as an MP4.

## Coordinate convention

nuScenes LiDAR frame: `index0 = lateral (left/right)`, `index1 = longitudinal
(forward/back)`. BEV plotting: x-axis = lateral, y-axis = longitudinal,
ego heading points up. Both scripts use this convention consistently.

## Requirements

Either:

- **Docker** (recommended — guarantees identical results on any machine), or
- **Local Python 3.10** with the packages in `requirements.txt`, plus `ffmpeg`
  for video export (`step12` only).

## Get the nuScenes dataset

This repository does **not** include the dataset (its license prohibits
redistribution). To obtain it:

1. Register at <https://www.nuscenes.org/nuscenes>.
2. Download the **Mini** split (`v1.0-mini`, ~4 GB) or a full split.
3. Extract so that `v1.0-mini/`, `samples/`, `sweeps/`, and `maps/` sit
   alongside each other under one directory.

## Run with Docker (recommended)

### 1. Build the image
```bash
docker build -t bev-vis .
```

### 2. Run

Run this from the project folder that contains `Dockerfile`, your `v1.0-mini/`
dataset folder, and an `output/` folder (create it first if it doesn't exist:
`mkdir -p output`).

**`step12_video_highlight.py`** (non-interactive, safe to run as shown):

```bash
cd ~/bev-vis   # the folder containing Dockerfile, v1.0-mini/, and output/

docker run --rm \
  -v "$(pwd)/v1.0-mini:/data:ro" \
  -v "$(pwd)/output:/app/output" \
  -e NUSC_ROOT=/data \
  -e OUT_DIR=/app/output \
  bev-vis \
  python step12_video_highlight.py --scene 0
```

**`step10_final.py`** (interactive — prompts for scene/frame numbers, so the
container needs `-it` to accept keyboard input):

```bash
docker run --rm -it \
  -v "$(pwd)/v1.0-mini:/data:ro" \
  -v "$(pwd)/output:/app/output" \
  -e NUSC_ROOT=/data \
  -e OUT_DIR=/app/output \
  bev-vis \
  python step10_final.py
```

Or skip the prompts and auto-pick a frame:

```bash
docker build -t bev-vis .
```

## Run locally (conda)

```bash
conda create -n bev_vis python=3.10 -y
conda activate bev_vis
pip install -r requirements.txt
conda install -c conda-forge ffmpeg -y   # needed for step12's video export

# set NUSC_ROOT as an environment variable, or edit the default inside the script
python step10_final.py
python step12_video_highlight.py --scene 0
```

## Usage

```bash
python step10_final.py                       # interactive scene/frame picker
python step10_final.py --auto                 # auto-pick the most active frame

python step12_video_highlight.py              # scene 0, video output
python step12_video_highlight.py --scene 3    # a specific scene
```

`NUSC_ROOT` and `OUT_DIR` environment variables override the dataset path
and output directory for both scripts; both default to sensible local paths
if unset.
